Demo walkthrough for the client meeting
  1. Waitress: open Table 11, press Send to kitchen. Serve Table 7, which is already ready.
  2. Kitchen: start Table 11, then mark it ready. The Waitress tab lights up.
  3. Waitress: mark Table 11 served, then Request bill.
  4. Cashier: take Table 11 by Telebirr with a transaction number, then close the shift.
  5. Verifier: open the morning shift, check statements, see the Br 250 shortage, flag it to the owner.
  6. Manager: open the daily report. Owner: see the month and the flagged shift.
Sample data for the demo: the hotel, staff, prices and amounts are made up.
